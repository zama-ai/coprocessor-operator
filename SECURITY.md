# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities confidentially through
[GitHub private vulnerability reporting](https://github.com/zama-ai/coprocessor-operator/security/advisories/new).
Do not open public issues for security vulnerabilities.

Include the affected chart or script, version, reproduction steps, and potential
impact so that we can investigate the report.

## Supported Versions

Security fixes are provided for the latest released version of each chart.
Please upgrade to the latest release before checking whether an issue persists.

## Response Timeline

We aim to acknowledge reports within 48 hours and provide a resolution timeline
within 7 days.
